# Report format
- Lead with the decision or result in one sentence. Then: what changed, evidence (check names and numbers), assumptions, what is unproven, next step.
- Use the exact words modeled / built / measured. Quote numbers with their source file (data/results/*.json, docs/figures/*.png).
- Include a corrections line when a prior statement changed.
- Tables for parameters; one figure per decision; no marketing language, no "record" claims.
- Sources of truth: docs/DESIGN_STATE.md, data/results/, stl/MANIFEST.csv, docs/CORRECTIONS.md, docs/OPEN_ITEMS.md.
