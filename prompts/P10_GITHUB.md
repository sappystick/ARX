# P10 Publish
Run scripts/push_to_github.sh yourself (it needs your credentials; Claude must not handle tokens). It initialises git and pushes to https://github.com/sappystick/ARX.git (pass another URL as the first argument). STLs are stored as plain git binaries (no Git LFS; see .gitattributes). Check that work/ is not committed and that large formers are not in git.
